# PDF-ийн фонт

Энэ хавтас нь **dompdf**-ийн фонтын кэш (чөлөөний хүсэлт, ээлжийн амралтын PDF).
Laravel автоматаар бөглөнө — гараар юм нэмэх шаардлагагүй.

Гэрээ / ажлын байрны тодорхойлолтын PDF нь **mPDF**-ээр гардаг бөгөөд
кирилл дэмждэг DejaVu фонтыг өөртөө агуулсан тул тусад нь фонт хэрэггүй.
