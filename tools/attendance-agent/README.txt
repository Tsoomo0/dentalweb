DentaSuite ирцийн агент — ресепшний компьютерт суулгах
=====================================================

Энэ программ салбарын хурууны хээний төхөөрөмжөөс (4370 порт) ирцийг 5 минут тутам
уншиж DentaSuite руу илгээнэ. Python суулгах шаардлагагүй.

СУУЛГАХ
-------
1. Энэ хавтсыг бүхлээр нь C:\DentaSuite\Attendance\ болгож хуулна.
   (Desktop, Downloads биш — устгагдах, нэр солигдох эрсдэлгүй газар.)

2. DentaSuite → HR → Ирцийн төхөөрөмж хуудсанд энэ салбарын төхөөрөмжийг нэмэх үед
   шар хайрцагт "агентын тохиргоо" гарна. "Хуулах" товч дарна.

3. Notepad нээж хуулсан зүйлээ буулгаад C:\DentaSuite\Attendance\config.json нэрээр хадгална.
   (Хадгалахдаа "Save as type: All files" сонгоно — config.json.txt болохгүй байх ёстой.)

4. install-task.bat дээр хоёр товшино.
   Хэдэн секундийн дараа "Ирцийн агент — амжилттай" цонх гарч төхөөрөмжийн SN,
   хэрэглэгч/бүртгэлийн тоо, "Сервертэй холбогдлоо ✓" харагдвал болсон.

5. Windows "Windows protected your PC" гэвэл: More info → Run anyway.

ШАЛГАХ
------
- Ажиллаж байгаа эсэх: энэ хавтас дахь agent.log файлын сүүлийн мөрүүд
  ("Илгээв: ... шинэ") 5 минут тутам нэмэгдэж байх ёстой.
- Task Scheduler → "DentaSuite Attendance Agent" → Last Run Result = 0x0.

АНХААР
------
- Анх суулгахад өмнөх сарын 1-нээс хойшхи бүртгэлийг л илгээнэ (төхөөрөмж олон жилийн
  түүх хадгалдаг). Илүү хуучин түүх хэрэгтэй бол config.json-д "since": "2025-01-01",
  мөрийг нэмээд state.json-ийг устгана.
- Компьютер шөнө унтарч болно — бүртгэл төхөөрөмж дотор хадгалагдаж, өглөө асахад татагдана.
- Төхөөрөмжийн IP-г өөрчилбөл config.json доторх "ip"-г засна.
- state.json, agent.log файлыг устгах хэрэггүй.

УСТГАХ
------
uninstall-task.bat дээр хоёр товшоод хавтсыг устгана.
